# Dessert Bowl 一碗甜品 — Demo Landing Page

A demo landing page for **Dessert Bowl 一碗甜品**, a traditional Chinese dessert
shop at 80A Serangoon Garden Way, Singapore (Google 4.5★, 1,300+ reviews).

Built as a sales demo: what the shop's website could look like, using
components from [21st.dev](https://21st.dev) (React + Tailwind + shadcn-style
blocks) and AI-generated food photography.

## Sections

- Sticky header with WhatsApp order CTA
- Hero with signature durian mousse photography
- Scrolling marquee of signature dishes
- Stats band (since 2008, 4.5★, 1,300+ reviews, open till late)
- Signature bowls gallery with category filters and lightbox
- Full menu with prices (4 courses, leader-dot price layout)
- Customer reviews, FAQ accordion, visit CTA, footer with hours

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

The live demo is published with GitHub Pages from the `gh-pages` branch.
